# 数据来源说明

## 当前内置数据源

当前版本优先使用 `scikit-learn` 内置的 `load_digits` 数据集作为离线可复现的真实数字图片数据源。

该数据集包含真实手写数字样本，来源为扫描表单中的手写数字。原始图像尺寸为 8x8 灰度图。本项目会将其等比例放大到 28x28 并保存为 PNG 文件，作为后续四位验证码构建的基础数字图片。

## 数据使用边界

- 数据源是真实手写数字样本。
- 项目不会用程序随机绘制数字作为主要训练数据。
- 项目不会用 AI 图片生成模型创建训练数字图片。
- 项目允许对真实数字图片进行轻度增强，例如模糊、旋转、噪声和轻微扭曲。

## 后续可扩展数据源

后续可以接入更多真实数字图片数据，例如：

- MNIST 或 EMNIST。
- 真实印刷票据、表格、门牌、仪表读数中的数字裁剪图。
- 公开真实验证码数据集。
- 人工标注的真实数字图片。

新增数据源时，需要在本文件中补充数据来源、许可、规模和处理方式。
